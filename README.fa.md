این مخزن دو پروژه دارد که یک موضوع را از دو طرف آموزش می‌دهند:

| پروژه | چیست | شروع از |
|---|---|---|
| **ArchLab** | یک برنامهٔ وب تعاملی. گیت‌ها را تغییر می‌دهید، یک CPU را گام‌به‌گام اجرا می‌کنید، کش را امتحان می‌کنید، مخاطرات خط لوله را می‌سازید و نتیجه را می‌بینید. رابط به دو زبان انگلیسی و فارسی (راست‌به‌چپ) است. | [پوشهٔ webapp](webapp/) |
| **cpu-cache-lab** | یک آزمایشگاه اندازه‌گیری. ریزبنچمارک‌های C++ و شبیه‌سازهای پایتون که سلسله‌مراتب کش، TLB، پیش‌بینی انشعاب، بهینه‌سازی ضرب ماتریس و false sharing را روی سخت‌افزار واقعی نشان می‌دهند. هر عدد از یک اجرای ثبت‌شده می‌آید، نه از فرض. | [پوشهٔ cpu-cache-lab](cpu-cache-lab/) |

این دو به هم کمک می‌کنند. فایل‌های `results/*.csv` آزمایشگاه به ArchLab منتقل می‌شوند؛
بنابراین صفحات سلسله‌مراتب حافظه می‌توانند بین اعداد کتاب درسی و اعداد اندازه‌گیری‌شده
روی یک ماشین واقعی جابه‌جا شوند، و ArchLab به شرح آزمایش پشت هر ادعا لینک می‌دهد.

## شروع سریع

### اجرای ArchLab

به [Node.js](https://nodejs.org) نسخهٔ ۲۰ یا بالاتر نیاز دارید.

</div>

```bash
./start.sh        # macOS / Linux  (on Windows: double-click start.bat)
```

<div dir="rtl">

اسکریپت در اولین اجرا وابستگی‌ها را نصب می‌کند، سرور توسعه را بالا می‌آورد و
<http://localhost:5180> را باز می‌کند. اگر ترجیح می‌دهید دستی انجام دهید:

</div>

```bash
cd webapp
npm install
npm run dev          # dev server with hot reload
npm run build        # one self-contained dist/index.html
```

<div dir="rtl">

### اجرای آزمایشگاه

به کامپایلر C++17، GNU make و Python 3.10 یا بالاتر نیاز دارید (برای رسم نمودار `matplotlib` و `numpy` هم لازم است).

</div>

```bash
cd cpu-cache-lab
make            # build all benchmarks into build/bin/
make test       # self-tests (correctness only)
make run        # measure; writes results/*.csv
make plot       # draw PNGs from the CSVs
```

<div dir="rtl">

کاربران ویندوز: از `g++` در MSYS2 UCRT64 استفاده کنند و دستورها را در MSYS2 یا Git Bash بزنند.
جزئیات، گزینه‌ها و راهنمای CMake در [README آزمایشگاه](cpu-cache-lab/README.md) (انگلیسی) آمده است.

بعد از اندازه‌گیری دوباره، با `npm run lab:data` اعداد نمایش‌داده‌شده در ArchLab را به‌روز کنید.

## ماژول‌های ArchLab

| # | ماژول | موضوعات |
|---|---|---|
| ۱ | منطق و سیستم‌های عددی | گیت‌ها و جدول درستی، جمع‌کننده‌ها، تبدیل مبنا، مکمل ۲، ضرب Booth |
| ۲ | طراحی دیجیتال | جبر بول، نقشهٔ کارنو، مالتی‌پلکسر و دیکودر، فلیپ‌فلاپ، ثبات‌های شیفت و شمارنده، RAM و ROM |
| ۳ | CPU | انتقال ثبات و گذرگاه مشترک، ALU، مسیر داده واکشی-رمزگشایی-اجرا، یک اسمبلر کوچک، نمودار ASM و طراحی کنترل |
| ۴ | حافظه | سلسله‌مراتب حافظه (کتاب درسی و اندازه‌گیری‌شده)، شبیه‌ساز کش، محلیت، حافظهٔ مجازی و TLB، همدوسی MSI/MESI |
| ۵ | خط لوله | مخاطرات، فورواردینگ، توقف و مدیریت انشعاب روی نمودار گانت |
| ۶ | انیمیشن‌ها | انیمیشن‌های کوتاهی که زنده در مرورگر از روی کد کشیده می‌شوند (بدون فایل ویدیو) |

## آزمایشگاه چه چیزهایی را اندازه می‌گیرد

| آزمایش | به چه پرسشی پاسخ می‌دهد |
|---|---|
| Pointer chase | با بزرگ‌تر شدن مجموعهٔ کاری از L1 و L2 و L3، تأخیر چگونه رشد می‌کند؟ |
| اندازهٔ خط کش، associativity، TLB | اندازهٔ خط کش و associativity سطح L1 چقدر است و ترجمهٔ آدرس چه هزینه‌ای دارد؟ |
| پیش‌بینی انشعاب، تأخیر دستور | پیش‌بینی غلط چقدر هزینه دارد و تأخیر با توان عملیاتی چه فرقی دارد؟ |
| نردبان ضرب ماتریس | ترتیب حلقه، کاشی‌بندی، SIMD، بلوک‌بندی و نخ‌ها چقدر کمک می‌کنند؟ (روی ماشین مرجع از ۰٫۷ تا ۲۲ گیگافلاپس) |
| شبیه‌سازهای کش و همدوسی | آیا افت نرخ برخورد در شبیه‌ساز با اندازهٔ کش واقعی می‌خواند؟ false sharing چقدر ترافیک می‌سازد؟ |
| false sharing و roofline | padding روی نخ‌های واقعی چه سودی دارد و هر هسته کجای محدودیت‌های ماشین قرار می‌گیرد؟ |

راهنمای هر آزمایش در [فهرست راهنماهای آزمایشگاه](cpu-cache-lab/docs/README.md) است (به انگلیسی).

## پشتیبانی از فارسی

با کلید **EN | فا** در نوار کناری، کل رابط ترجمه می‌شود. چیدمان راست‌به‌چپ می‌شود، از فونت
Vazirmatn استفاده می‌شود و انتخاب شما به خاطر سپرده می‌شود. نمودارها و برچسب‌های فنی
(نام ثبات‌ها، mnemonicها، مبنای ۱۶) عمداً چپ‌به‌راست و لاتین می‌مانند.

## دستورهای مفید

از ریشهٔ مخزن اجرا کنید:

| دستور | کار |
|---|---|
| `npm start` | سرور توسعهٔ ArchLab |
| `npm run build` | ساخت سایت تک‌فایلی در `webapp/dist/index.html` |
| `npm run preview` | سرو محلی سایت ساخته‌شده |
| `npm run typecheck` | بررسی TypeScript |
| `npm run i18n:check` | یافتن ترجمه‌های فارسی جاافتاده یا تکراری |
| `npm run ci` | typecheck، بررسی i18n و build (آنچه CI برای وب‌اپ اجرا می‌کند) |
| `npm run lab:build`، `lab:test`، `lab:run`، `lab:plot` | ساخت، آزمون، اندازه‌گیری و رسم آزمایشگاه |
| `npm run lab:data` | انتقال نتایج آزمایشگاه به ArchLab |
