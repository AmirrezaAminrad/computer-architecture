# Security Policy

ArchLab is a static, client-side web app and a local measurement lab; it has no server
component and collects no data. If you still find a vulnerability (for example in a
dependency or the build pipeline), please report it privately through GitHub's
**Security → Report a vulnerability** form rather than a public issue. You can expect an
initial response within a few days.

Only the latest release on `main` is supported.
